# Tournament asset credits

`philippine-one-peso-obverse.png` and `philippine-one-peso-reverse.png` are photographs of the 2018 Philippine New Generation Currency 1-Piso coin by Wikimedia Commons user Itsquietuptown. The source images are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). They were resized to 960 × 960 pixels for use in the tournament coin-toss interface.
